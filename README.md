CraftyBay - Flutter E-Commerce App

CraftyBay is a modern Flutter-based e-commerce application built with Dart and Flutter. The app provides a complete shopping experience including user authentication, product browsing, categories, product details, cart management, and a clean responsive UI.

📱 Features
- User Authentication
 - OTP-based Login
- JWT Token Management
- Product Slider
- Product Categories
- New Products
- Popular Products
- Special Products
- Product Details
- Add to Cart
- Cart Management
- Delete Cart Items
- User Profile
- Light & Dark Theme
- English & Bangla Language Support
- Responsive UI
- API Integration
- Error Handling
- Loading States
  
🛠️ Technologies & Packages
- Flutter
- Dart
- GetX - State Management & Navigation
- REST API - Backend communication
- HTTP - API requests
- SharedPreferences - Local token storage
- Firebase - Authentication/Cloud services where applicable
